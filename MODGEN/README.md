# Go Back To Your Biome

This mod helps you prevent which night spawns can happen when they are triggered by the bosses you have defeated previously. 

Initially these spawns are DISABLED after you install the mod. You can enable them back in the configuration and do more if you keep reading.

# IMPORTANT

* Global keys are NOT altered.
* The indicated spawns in the configuration file are just canceled when they happen, so the game events are not altered either.

# Hot it works

* Enable/disable them individually by biome (all disabled by default)
* If vanilla game or other mods introduce similar behavior with other global keys, you can add them in the free text in the .cfg option as well separated by comma

![](https://i.imgur.com/AzRvNBq.png)

* If sick of some night specific monsters, add their prefab ids to a list to the biome you don't want them to spawn.
* If playing on custom biomes, add them with the indicated format. Example: biomeName1:id1;biomeName2:id2,id3,id4

![](https://i.imgur.com/hoOca5y.png)
